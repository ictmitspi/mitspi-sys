# Software Requirements Specification — MITSPI Room Booking

The SRS lives in Claude Docs, so it can be exported to Word or PDF:
https://claude.ai/artifact/FWFRTEGDyqPUcg7a6Bo9ZF

It holds the functional requirements (FR-01 – FR-24), the non-functional requirements
(NFR-01 – NFR-09), the constraints, and 6 diagrams: system context, use cases, data model,
the booking and admin-change swimlanes, and deployment.

When you add a feature, add its requirement there with the next free ID. Never reuse an ID.
